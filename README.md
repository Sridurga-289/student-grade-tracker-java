# 🎓 Student Grade Tracker

A Java Swing desktop application for managing student grades and analyzing student performance.

## 📌 Project Overview

Student Grade Tracker is a simple and user-friendly Java application that allows users to add student information, calculate grades automatically, search for students, and view overall class performance.

The project demonstrates Java programming concepts such as **Object-Oriented Programming, ArrayList, GUI development, event handling, and data management**.

## ✨ Features

* ➕ Add student details
* 🆔 Store Student ID
* 👤 Store Student Name
* 📝 Enter student marks
* 🎯 Automatically calculate grades
* 🔍 Search students by Student ID
* 📊 Display total number of students
* 📈 Calculate average marks
* 🏆 Display highest marks
* 📉 Display lowest marks
* ✅ Validate student input
* 🖥️ User-friendly Java Swing GUI

## 🛠️ Technologies Used

* **Java**
* **Java Swing**
* **ArrayList**
* **Object-Oriented Programming**
* **AWT Event Handling**

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Sridurga-289/student-grade-tracker-java.git
```

### 2. Open the project

Open the project folder in **VS Code, IntelliJ IDEA, Eclipse, or another Java IDE**.

### 3. Compile the Java files

```bash
javac src/*.java
```

### 4. Run the application

```bash
java -cp src Main
```
